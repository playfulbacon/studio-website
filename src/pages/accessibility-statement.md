We want everyone to be able to enjoy this website. It was built with
accessibility in mind:

- Semantic HTML with a logical heading structure and landmark regions
- Text and interactive elements meet WCAG 2.1 AA color-contrast guidelines
- All functionality, including the FAQ and forms, works with a keyboard alone
- Images include alternative text; icons are labelled for screen readers
- The layout adapts to any screen size and to browser zoom up to 400%
- Animations and smooth scrolling are disabled when your system asks for
  reduced motion

## Found a problem?

Accessibility is an ongoing effort. If anything on this site is hard to use
with assistive technology, we'd genuinely like to know. Email us at
[hello@kettle.games](mailto:hello@kettle.games) and we'll do our best to fix
it promptly.
